# Eyewear management

Web app quản lý đơn kính của cửa hàng, thay cho file Google Sheets "Danh sách kính" (sheet ngày, KÍNH HẸN, SỰ CỐ, TỔNG).

**Repo public**: không commit dữ liệu bệnh nhân thật (tên, SĐT, độ kính, file .xlsx/.csv export từ Sheets).
